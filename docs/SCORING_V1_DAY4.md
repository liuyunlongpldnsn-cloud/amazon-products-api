# Scoring V1 (Day 4)

评分模型目标是用一套可解释、可复现的规则，在同一批耳机候选中快速筛出更值得推荐的商品。当前总分由 3 个分项组成：价格分、口碑分、参数分。价格分看同批商品内的相对位置，越便宜分越高；口碑分综合评分与评论量，评分高且评论多更稳定；参数分根据关键参数数量与命中高价值特征（如 ANC、防水、续航）给分。默认权重为 `price 35% + review 40% + spec 25%`。当 `rating` 或 `review_count` 缺失时，口碑分直接记 0，避免模型把不完整数据误判为高可信。这样设计能先保证稳健排序，后续可继续加入品牌、历史价格波动、延迟场景等更细分维度。
